# Agent Guard

Open-source security scanner for AI agents and tools.

## Status

🚧 Em desenvolvimento

## Objetivo

O Agent Guard tem como objetivo analisar ferramentas utilizadas por agentes de IA e identificar possíveis riscos de segurança, como:

- Excessive Agency
- Permissões excessivas
- Operações destrutivas
- Exposição de informações sensíveis
- Ausência de controles de segurança

## Stack

- Python
- FastAPI
- Pydantic
- Pytest
- Docker
- GitHub Actions
